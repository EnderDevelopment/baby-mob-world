# Baby Mob World

Baby Mob World is a Minecraft Java Edition mod that adds baby variants of various mobs with custom textures, animations, and behaviors. These baby mobs are designed to be non-aggressive while they are learning, allowing players to raise and tame them using a special item called a Mob Catcher. The mod is compatible with Minecraft Java Edition and the Fabric mod loader.

## Install

1. Ensure you have Minecraft Java Edition installed.
2. Install the Fabric mod loader by following the instructions on the [Fabric website](https://fabricmc.net/).
3. Download the Baby Mob World mod from the [GitHub repository](https://github.com/enderdevelopment/baby-mob-world).
4. Place the downloaded mod file in the `mods` folder of your Minecraft installation directory.
5. Launch Minecraft using the Fabric profile.

## Use

1. Craft a Mob Catcher using the appropriate materials.
2. Use the Mob Catcher to capture baby mobs.
3. Raise and tame the baby mobs to make them your allies.
4. Enjoy the unique textures, animations, and behaviors of the baby mobs.
